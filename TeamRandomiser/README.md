# Рандомайзер Команды

Рандомизирует перки и предметы для убийцы и четырёх выживших. Ассеты (перки, портреты, предметы) берутся из общей папки `../assets/dbd`, русские названия — из словарей `../Roulette/data`.

## Файлы

- `index.html` / `style.css` / `script.js` — сама страница (ванильный JS, без сборки).
- `data.json` — сгенерированный список перков/персонажей/предметов.
- `tools/build-data.mjs` — генератор `data.json`. После добавления новых картинок в `assets/dbd` запусти из корня репозитория:

  ```
  node TeamRandomiser/tools/build-data.mjs
  ```

  Скрипт напишет, для каких файлов не нашлось русского названия (добавь их в словари Roulette или в overrides внутри скрипта).

- `_legacy/` — исходный прототип из DevComponents.

## Механика

- Тир перка = папка Tier1/2/3 в `assets/dbd/…Perks` (обычный / редкий / легендарный). Шансы у выживших: 1% на Tier 0, 20% на III, 30% на II, остальное I; у убийцы: 30% на III, 40% на II.
- Tier 0 (папка `assets/dbd/survivorPerks/Tier0`, чёрный ромб, свой звук `sfx/Tier0.mp3`) — только в рандомайзере, в лавку капитана не попадает.
- Перки не повторяются: у убийцы — в рамках его четырёх слотов, у выживших — во всей команде (поэтому перки можно перетаскивать между слотами и игроками).
- Предметы уникальны между выжившими; редкости: Обычный (коричневый) / Необычный (зелёный) / Редкий (синий) / Очень редкий (фиолетовый) / Ивентовый (золотой — петарды). Шансы: 30% фиолетовый, 25% синий, 20% зелёный, 15% коричневый, 10% ивентовый. Предметы тоже можно перетаскивать между выжившими.
- Убийцы и выжившие в пикерах отсортированы по дате выхода в DBD (порядок задан в `tools/build-data.mjs`).
- Выбор персонажей и результаты сохраняются в localStorage.
